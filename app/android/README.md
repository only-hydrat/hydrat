# Hydrat App для Android

Приложение рассчитано на arm64 и Android 10 или новее. Оно импортирует подписки и мосты Tor в локальное хранилище и подключает системный VPN. Служебные соединения Hydrat используют физическую сеть. Обычные приложения направляются в системный туннель, где Hydrat применяет правила маршрутизации.

На «Главной» видны состояние VPN, ход поиска, основные и резервные маршруты TCP и UDP. В «Подключениях» можно добавлять, обновлять и удалять источники, в том числе подписки из публичной подборки Hydrat. «Настройки» управляют DNS, региональными правилами, параллельными проверками, порогом качества и фоновой работой. Параметры туннеля и поиска применяются после переподключения VPN. Пользовательский HWID применяется со следующего запроса на HTTPS-адрес подписки.

### GeoIP и GeoSite

В настройках откройте «Источники и правила GeoIP / GeoSite». Можно указать отдельную HTTPS-ссылку на каждую базу Xray в формате `.dat`. Пустая ссылка выбирает базу из приложения. Имена групп для VPN и прямого доступа вводятся через запятую. Правила VPN проверяются раньше прямых. Пустой список отключает соответствующее географическое правило.

Hydrat проверяет базы и указанные группы при сохранении. Настройки вступают в силу при следующем подключении.

## Локальная сборка

Для сборки на Linux x86-64 нужны JDK 17, Gradle 8.13, Android SDK 35, NDK r28c, Go 1.27.1, Perl, make и стандартные инструменты сборки. Укажите `ANDROID_HOME` и `ANDROID_NDK_HOME`. Подготовьте `geoip.dat` и `geosite.dat` с наборами правил, указанными в [конфигурации шлюза](../../config/config.yml).

Из корня репозитория:

```sh
transports="$(mktemp -d)"
./scripts/build-app-android-transports.sh "$transports"
./scripts/build-app-android.sh /path/to/geo "$transports"
```

Gradle сохраняет APK для тестирования в `app/android/build/outputs/apk/debug`. APK подписывается локальным отладочным ключом.

Передайте третьим аргументом `release`, чтобы собрать неподписанный APK для публикации. Перед выпуском его нужно выровнять через `zipalign -P 16` и подписать постоянным ключом проекта через `apksigner`. Версию всех приложений задаёт `internal/appupdate/version.txt`.

## Проверки на телефоне

После локальной сборки выполните:

```sh
gradle -p app/android lintDebug testDebugUnitTest connectedQaAndroidTest
```

Тесты интерфейса используют отдельный пакет `org.hydrat.app.qa` со своим хранилищем. Понадобится подключённое по ADB устройство arm64 с разблокированным экраном.

После импорта подписки выдайте системное разрешение VPN. Проверьте TCP, UDP и DNS при использовании VLESS, TCP через Tor с мостами obfs4 и webtunnel, а также смену сети между Wi-Fi и мобильной связью. При отсутствии рабочего маршрута защищённые запросы должны блокироваться. Проверьте отдельно блокировку IPv6, восстановление маршрутов после отключения, расход батареи и запуск на устройстве со страницами памяти 16 КБ.
