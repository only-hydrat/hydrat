# Hydrat для Windows

Hydrat для Windows 10/11 x64 доступен как MSI и переносимый ZIP.

1. Запустите MSI и откройте Hydrat из меню «Пуск». Для переносимой сборки распакуйте ZIP целиком и откройте `Hydrat.exe`. Подтвердите запрос Windows на права администратора для запуска Wintun.
2. Нажмите «Добавить источник» на главной. Вставьте ссылки и конфиги, затем нажмите «Импортировать», или добавьте подписки из каталога Hydrat. Если часть строк требует исправления, Hydrat оставит их в форме и покажет причину.
3. Нажмите «Подключить». В разделе «Маршруты» появятся текущие TCP- и UDP-маршруты и их резервы. Tor используется для TCP.

«Отключить» останавливает туннель. При закрытии окна Hydrat остаётся в области уведомлений. Чтобы полностью выйти, выберите «Выход» в меню значка Hydrat.

Настройки DNS, поиска, обновления подписок и GeoIP/GeoSite применяются при следующем подключении. По умолчанию Hydrat запускает до 8 быстрых проверок при поиске маршрута и до 4 в фоне, обновляет подписки раз в час и использует порог VLESS 75.

Источники, история проверок и журнал сохраняются в `%LOCALAPPDATA%\Hydrat`. MSI сохраняет эту папку при обновлении и удалении приложения. При ошибке запуска журнал можно открыть с главной.

## Сборка из исходников

В Linux или WSL подготовьте официальный [Wintun 0.14.1](https://www.wintun.net/), [Tor Expert Bundle для Windows x86_64](https://www.torproject.org/download/tor/) и файлы `geoip.dat`, `geosite.dat`. Для Tor проверьте подпись архива. Из корня проекта выполните:

```sh
./scripts/build-app-windows.sh wintun-0.14.1.zip tor-expert-bundle.tar.gz ./geo ./Hydrat-windows-x64.zip
```

Для MSI установите `wixl` и `msitools`, затем соберите установщик из полученного ZIP.

```sh
./scripts/build-app-windows-msi.sh ./Hydrat-windows-x64.zip ./Hydrat-windows-x64.msi "$(cat internal/appupdate/version.txt)"
```
