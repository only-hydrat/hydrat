{{t "Сайты .i2p и адресная книга"}}

{{t "Сайты I2P открываются через подключение WireGuard. Отдельное приложение и настройка прокси не нужны. Обычные сайты продолжают работать через свои маршруты."}}

{{t "Первое подключение"}}

  1. {{t "В Hydrat откройте «Клиенты» и нажмите «Доступ к .i2p» у своего устройства. Если у вас нет прав администратора, попросите его включить доступ. В «Моём подключении» должен появиться статус «Разрешён»."}}
  2. {{t "Включите WireGuard. В его конфигурации оставьте DNS, выданный Hydrat. Подключение должно направлять трафик через VPN; не исключайте из него браузер."}}
  3. {{t "Отключите в браузере собственный DNS через HTTPS по инструкции ниже: адреса I2P должен разрешать шлюз Hydrat."}}
  4. {{t "Откройте полный адрес сайта, например"}} http://i2pforum.i2p/{{t ". При первом запуске добавляется 71 имя из официальной адресной книги I2P;"}} forum.i2p {{t "в ней нет. Для остальных коротких имён добавьте запись или подписку. Полный адрес"}} .b32.i2p{{t ", полученный у владельца сайта, можно открыть без добавления записи."}}
{{t "Android: Firefox и Chrome"}}

{{t "Firefox: меню ⋮ → «Настройки» → «Конфиденциальность и безопасность» → «DNS через HTTPS» → «Выкл.». Для .i2p подходит обычный Firefox: менять about:config не требуется."}}

{{t "Chrome: меню ⋮ → «Настройки» → «Конфиденциальность и безопасность» → «Использовать безопасный DNS» → выключить. Названия пунктов могут немного отличаться между версиями."}}

{{t "Если в Android задан сторонний «Частный DNS», найдите его через поиск системных настроек и временно выключите. Убедитесь, что Firefox или Chrome не исключён из туннеля WireGuard."}}

{{t "Компьютер: Firefox, Chrome и Edge"}}

{{t "Firefox: «Настройки» → «Приватность и защита» → «DNS через HTTPS» → «Выкл.»."}}

{{t "Chrome: «Настройки» → «Конфиденциальность и безопасность» → «Безопасность» → выключить «Использовать безопасный DNS». В Edge найдите «Безопасный DNS» через поиск настроек и выключите его."}}

{{t "В WireGuard сохраните DNS из конфигурации Hydrat. Расширения с собственным прокси или DNS могут обходить VPN — отключите их для этой проверки."}}

{{t "iPhone и iPad"}}

{{t "Включите профиль WireGuard с DNS Hydrat и откройте полный адрес в Safari. Если установлен отдельный профиль защищённого DNS или приложение, меняющее DNS, временно отключите его для проверки. Не удаляйте профиль управления устройством."}}

{{t "Работа на физических iPhone/iPad отдельно не проверена. Если имя не определяется, проверьте разрешение I2P и адресную книгу у администратора."}}

{{t "Как добавить сайт и подписку"}}

{{t "Администратор добавляет сайт ниже, в «Адресной книге»: имя"}} {{t "имя.i2p"}} {{t "и публичный Destination либо"}} .b32.i2p{{t ", полученный у владельца сайта. Придуманное имя без такой записи не откроется."}}

{{t "Готовый список можно вставить в «Импорт и экспорт hosts.txt»: нажмите «Проверить импорт», разберите ошибки и подтвердите импорт. Для регулярного обновления добавьте URL в «Подписки адресной книги» и нажмите «Обновить». Новые имена добавятся автоматически, замену известных адресов нужно подтвердить."}}

{{t "Если сайт долго не открывается"}}

{{t "После сна I2P заново строит туннели. Дождитесь прогрева и обновите страницу; администратор может нажать «Прогреть сейчас». Статус «Прогрет» не гарантирует доступность каждого сайта."}}

{{t "Если другой I2P-сайт работает, возможно, недоступен именно этот адрес. Если не работает ни один, проверьте разрешение клиента, DNS и записи адресной книги. Если браузер пытается заменить HTTP на HTTPS, для сайта без HTTPS разрешите HTTP только для этого сайта; проверку сертификатов не отключайте."}}

{{t "Для завершения просто закройте страницы I2P: после периода ожидания процесс уснёт. Администратор может выключить доступ у клиента. Настройки DNS браузера можно вернуть к прежним значениям."}}

{{t "Чужой трафик не ретранслируется. Участники I2P, с которыми соединяется шлюз, видят его IP. Обычный браузер сохраняет свои cookies и отпечаток."}}

{{t "Доступ к .onion через Tor"}}

{{t "Администратор разрешает доступ отдельно для каждого клиента. Обычные сайты продолжают использовать свои маршруты. Для .onion нужен готовый Tor-профиль; поддерживаются публичные v3-адреса и TCP."}}
