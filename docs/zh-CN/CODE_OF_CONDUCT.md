# Contributor Covenant 行为准则

## 我们的承诺

作为社区成员、贡献者和负责人，我们承诺让每个人都能在不受骚扰的环境中参与社区，无论其年龄、体型、可见或不可见的残障、族裔、性别特征、性别认同与表达、经验、教育程度、社会经济地位、国籍、外貌、种族、种姓、肤色、宗教、性身份或性取向如何。

我们承诺以有助于建立开放、友善、多元、包容且健康社区的方式行事和互动。

## 行为标准

有助于营造积极社区环境的行为包括：

* 对他人表现同理心与善意；
* 尊重不同的意见、观点和经历；
* 提供并坦然接受建设性反馈；
* 为错误承担责任，向受影响的人道歉，并从中吸取经验；
* 不仅考虑个人利益，也关注整个社区的最佳利益。

不可接受的行为包括：

* 使用带有性意味的语言或图像，以及任何形式的不受欢迎的性关注或示好；
* 挑衅、侮辱、贬损性评论，以及人身或政治攻击；
* 公开或私下骚扰；
* 未经明确许可发布他人的私人信息，例如住址或电子邮件地址；
* 其他在专业环境中可被合理认定为不当的行为。

## 执行责任

社区负责人有责任解释并执行可接受行为标准，并对其认定为不当、威胁、冒犯或有害的行为采取适当且公平的纠正措施。

社区负责人有权并有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 修改、Issue 及其他贡献，并在适当情况下说明采取管理措施的原因。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共场合正式代表社区的情况。代表社区的示例包括使用官方电子邮件地址、通过官方社交媒体账户发布内容，或作为指定代表参加线上或线下活动。

## 执行

如遇辱骂、骚扰或其他不可接受的行为，可通过 only_hydrat@proton.me 向负责执行准则的社区负责人报告。所有投诉都会得到及时、公平的审查和调查。

所有社区负责人都必须保护事件报告者的隐私和安全。

## 执行指南

社区负责人将依据以下社区影响指南，确定违反本行为准则的行为应承担的后果。

### 1. 纠正

**对社区的影响：**使用不当语言，或实施被认为不专业、不受欢迎的其他行为。

**后果：**社区负责人发出私下书面警告，说明违规性质以及该行为为何不当，并可能要求公开道歉。

### 2. 警告

**对社区的影响：**一次事件或一系列行为构成违规。

**后果：**发出警告，并说明继续该行为的后果。在指定期限内，不得与相关人员互动，包括主动联系行为准则执行人员。该限制同时适用于社区空间和社交媒体等外部渠道。违反这些条件可能导致临时或永久封禁。

### 3. 临时封禁

**对社区的影响：**严重违反社区标准，包括持续的不当行为。

**后果：**在指定期限内禁止以任何形式与社区互动或公开交流。在此期间，不得与相关人员进行公开或私下互动，包括主动联系行为准则执行人员。违反这些条件可能导致永久封禁。

### 4. 永久封禁

**对社区的影响：**持续违反社区标准，包括长期不当行为、骚扰个人，或攻击、贬损某类群体。

**后果：**永久禁止在社区内进行任何形式的公开互动。
